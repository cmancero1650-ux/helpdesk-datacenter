# Help Desk SPA

Frontend React/Vite de la Actividad 9. La aplicacion se organiza en componentes para navegacion, dashboard, registro y listado de tickets.

## Uso local

```bash
npm install
copy .env.example .env
npm run dev
```

La variable `VITE_API_URL` debe apuntar a la URL publica o local del backend. Para compilar para hosting estatico:

```bash
npm run build
```

El contenido de `dist/` puede publicarse en Vercel, Netlify o GitHub Pages.
